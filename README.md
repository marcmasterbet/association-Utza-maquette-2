# UZTA — Maquette 02 : Éditorial contemporain

Projet Next.js pour Vercel.

## Démarrer
`npm install` puis `npm run dev`.

## Déploiement
Importer ce dépôt dans Vercel (framework Next.js).

## Remarques
- Textes de la page Accueil conservés à l'identique.
- Pages À propos et Blog sans contenu en attente des textes officiels.
- Liens d'appel à l'action temporairement dirigés vers la dernière section de la page Accueil.
- Logo fourni conservé dans `public/logo-uzta.jpg`.
